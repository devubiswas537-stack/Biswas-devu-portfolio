BISWAS DEVU — PORTFOLIO WEBSITE

RUN LOCALLY (EASIEST)
1. Extract the ZIP file.
2. Open the folder "biswas-devu-portfolio".
3. Double-click index.html. It opens in your browser.
   No installation, account, or payment is required.

OPTIONAL LOCAL SERVER
If you have Python installed, open a terminal in this folder and run:
  python -m http.server 8000
Then open http://localhost:8000

FREE HOSTING OPTION — GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a new public repository named biswas-devu-portfolio.
3. Upload index.html, styles.css, script.js, and the assets folder (keep the folder structure).
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch "main" and folder "/ (root)", then Save.
7. GitHub will show your free public website URL after deployment.

FREE HOSTING OPTION — NETLIFY DROP
1. Open https://app.netlify.com/drop
2. Sign in if prompted.
3. Drag the extracted "biswas-devu-portfolio" folder onto the page.
4. Netlify publishes it and gives you a public URL.

NOTES
- The website uses your uploaded portrait and details from your resume.
- Google Fonts is loaded online; if unavailable, fallback fonts will be used.
- Review your phone number and email before publishing publicly.
- The resume did not include exact placement counts or quantified placement rates, so the website does not invent them.
- Update your LinkedIn URL if you want a different profile link.
